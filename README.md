## 📊 Proyecto destacado

### Retail Sales & Cost Analytics

Proyecto de Business Intelligence desarrollado con Excel y Power Query para integrar información sintética de ventas y costos y presentar indicadores comerciales mediante un dashboard ejecutivo.

**Características principales:**

- 700 productos sintéticos.
- 2.089 registros de ventas y 2.089 registros de costos.
- Integración y agrupación automatizada mediante Power Query.
- Controles de calidad y conciliación de cantidades.
- Rankings Top 10 y alertas sobre diferencias comerciales.
- Documentación técnica, datos de demostración y dashboard descargable.

**[Ver proyecto completo en GitHub](https://github.com/cavargasg86/retail-sales-cost-analytics)**
